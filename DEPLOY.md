# Deploy to Railway in 5 Minutes

## Step 1: Push to GitHub
```bash
cd ~/projects/job-applier
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/job-applier.git
git branch -M main
git push -u origin main
```

## Step 2: Connect to Railway
1. Go to https://railway.app
2. Sign in with GitHub
3. Click "New Project" → "Deploy from GitHub Repo"
4. Select `job-applier` repository
5. Railway auto-deploys! ✨

## Step 3: Add PostgreSQL Database
1. In Railway: Click "Add Service" → "PostgreSQL"
2. Railway creates the database automatically

## Step 4: Set Environment Variables
In Railway Dashboard → Your Project → Variables:

```
CLAUDE_API_KEY=sk-ant-api03-xxxxxxx
NODE_ENV=production
```

Database variables are auto-generated by Railway.

## Step 5: Run Database Schema
Open Railway Shell and run:
```bash
psql $DATABASE_URL < db/schema.sql
```

Done! Your app is live at `https://your-project.up.railway.app` 🚀
